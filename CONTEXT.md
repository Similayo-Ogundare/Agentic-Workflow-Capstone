# Tithe and Offering Marvellous Church
This Is An Agentic System For Managing Tithes & Offering Invoices For A Church.
The name of the church is Marvellous Church.

The main goal is to review spreadsheet created every sunday for the last quarter (January-April) for a 19 member church. 

Note: As a Biblical rule of thumb, tithes are only paid on the first sunday of each month.

The important spreadsheet files for that month are located in the respective folders with the names of each month.
